# Contributing

Thank you for your interest in improving this RabbitMQ course. If you find a mistake, a comment on the episode's YouTube video is the most reliable way to report it.

## Guidelines

- Keep all documentation, comments, and example output in English.
- Keep each episode self-contained.
- Avoid introducing dependencies that are not required by the episode.
- Update the relevant README when changing setup instructions or example behavior.
- Do not commit credentials, local environment files, build output, or IDE-specific settings.

## Testing Changes

Before submitting changes:

1. Read the episode README.
2. Start the required services using the documented commands.
3. Run the available tests.
4. Verify that the examples behave as described.
5. Update the documentation if behavior or prerequisites have changed.

## Pull Requests

This repository is a companion to the video course, so Pull Requests and Issues may be disabled. If they are enabled, describe the purpose of the change, the episode it affects, and the steps used to verify it.
